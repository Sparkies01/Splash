# MLBB Hero Splash Images

Original-resolution Mobile Legends hero and skin splash images, organized into
one folder per hero.

## Download

Open the repository's **Releases** page and download all three ZIP archives:

- `MLBB-Splash-A-H.zip`
- `MLBB-Splash-I-Q.zip`
- `MLBB-Splash-R-Z.zip`

Each archive is independent and contains complete hero folders. Extract them
into the same destination folder to assemble the full collection.

## Collection

- 133 heroes
- 1,061 PNG images
- Hero and skin names are used as folder and file names

This is a community-maintained asset collection. Mobile Legends: Bang Bang and
its characters are property of their respective rights holders.
